# rhmaeda.dev SEO package

Upload all files/folders in this package to the root of the GitHub Pages repository.

Files:
- index.html — English / Ireland landing page
- pt/index.html — Portuguese version
- robots.txt — allows crawling and points to sitemap
- sitemap.xml — English + Portuguese URLs with hreflang
- favicon.svg — browser/search favicon
- og-image.png — social sharing preview image

After deployment:
1. Add `rhmaeda.dev` as a Domain property in Google Search Console.
2. Verify it using the TXT record Google gives you.
3. Submit `https://rhmaeda.dev/sitemap.xml`.
4. Inspect `https://rhmaeda.dev/` and click Request indexing.
5. Inspect `https://rhmaeda.dev/pt/` and request indexing.
